Interface: ComplexArray<T> ​

Defined in: src/entity/complex-array.ts:9

The value of a complex property that holds an array of complex objects. It is a real array: adding or removing an element marks the owning entity Modified, can be undone by rejectChanges, and raises the array's arrayChanged event with an ArrayChangedArgs.
