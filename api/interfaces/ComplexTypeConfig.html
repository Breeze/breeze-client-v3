The type's data properties: an object whose keys are property names and whose values are DataPropertyConfig objects, or an array of DataProperty instances or of DataPropertyConfig objects that each include a name.

isComplexType? ​

Defined in: src/metadata/entity-metadata.ts:2027

Set to true when passing this config to MetadataStore.addEntityType, which otherwise creates an EntityType. The ComplexType constructor does not need it.
